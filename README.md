# Painel de Frentes – Contrato 425

Versão pública, só de leitura, do painel de frentes de serviço do Contrato 425 (Sinarco · fiscalização Move · Prefeitura de Conceição do Mato Dentro).

- O site é o arquivo `index.html`, publicado pelo GitHub Pages.
- Os dados são lançados no painel interno e copiados para cá automaticamente. Não edite o `index.html` à mão.
- `ferramentas/gerar_site.py` gera o `index.html` a partir dos dados do painel e esconde telefones e e-mails.
